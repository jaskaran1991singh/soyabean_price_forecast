# Data dictionary — target-market soybean weekly features

Every column in `data/<market>_<commodity>/features/training_weekly.parquet` (and `.csv`), produced
by `src/soyfc/features/build.py`. One **row per week**, indexed by `week_end`. (Outputs are
partitioned per target market, e.g. `data/indore_soyabean/features/`.)

"Indore" below is the **configured target market** (`target.market` in `config/settings.yaml`),
used here as the running example. Set a different mandi and the same columns describe that market
instead — read "Indore" as "the target market" throughout.

**Point-in-time rule.** Each week has a `cutoff` = `week_end + forecast_lag_days` (Saturday, the
moment the forecast is issued). A feature value for week *W* uses only data whose `available_at`
is on or before *W*'s cutoff — so the training data never contains information from the future.

**How to read this.** Columns are grouped exactly as in `build.py`. Names with `<...>` are
**patterns** — one real column per item listed. "Availability" is the rule that decides when a
value is allowed into a week.

> A machine version (column, group, source, % filled, first date) is regenerated by
> `python -m soyfc build` at `data/features/data_dictionary.csv`; it only lists columns whose
> source was collected. This file documents the full set with descriptions.

---

## Index & meta

| column | description | unit |
|---|---|---|
| `week_end` | Friday the week ends on (the row index). | date |
| `cutoff` | Saturday the forecast is issued = `week_end + forecast_lag_days`. Not a feature; the as-of boundary. | date |

---

## `target_history` — target-market price & its history
**Source:** mandi_daily (Agmarknet / mandi-api / data.gov.in). **Availability:** `y` and the
week's own stats are known at the cutoff; lags/moving-averages/returns use past weeks only.

| column | description | unit |
|---|---|---|
| `y` | Indore weekly modal price = mean of the week's daily modal prices (arrival-weighted across varieties). **This is the level everything forecasts.** | Rs/qtl |
| `y_close` | Modal price on the last trading day of the week. | Rs/qtl |
| `y_range_pct` | Intra-week dispersion = (week max − week min) / `y`. | fraction |
| `trading_days` | Number of trading days in the week (0 = closed week: holiday/strike). | count |
| `y_lag1`…`y_lag4` | `y` 1–4 weeks ago (price carried over up to 3 closed weeks for lags only). | Rs/qtl |
| `y_ma4` | 4-week moving average of `y`. | Rs/qtl |
| `y_ma13` | 13-week (≈ quarter) moving average of `y`. | Rs/qtl |
| `ret_1w` | Weekly log return, `ln(y_t / y_{t-1})`. | log-return |
| `ret_4w` | 4-week log return, `ln(y_t / y_{t-4})`. | log-return |
| `ret_13w` | 13-week log return. | log-return |
| `vol_8w` | 8-week rolling std of weekly log returns (recent volatility). | log-return std |
| `y_vs_ma13` | `y / y_ma13 − 1` (distance from the quarterly trend). | fraction |
| `y_yoy` | `ln(y_t / y_{t-52})` (change vs the same week last year). | log-return |

## `arrivals` — supply pressure
**Source:** mandi_daily. **Availability:** the week's own arrivals.

| column | description | unit |
|---|---|---|
| `arrivals_wk` | Total soybean arrivals at Indore mandi this week. | tonnes |
| `arrivals_ma4` | 4-week moving average of weekly arrivals. | tonnes |
| `arrivals_yoy` | `ln((a+1)/(a_{t-52}+1))` — arrivals vs same week last year. | log-return |
| `arrivals_season_cum` | Season-to-date cumulative arrivals (crop year starts 1 Oct). | tonnes |

## `peer_mandis` — nearby markets (lead signals)
**Source:** mandi_daily. **Availability:** same week (obs_date ≤ week_end).
`<market>` ∈ {`ujjain`, `dewas`, `dhar`, `mandsaur`, `shajapur`, `sehore`, `latur`} (from
`settings.peer_markets`).

| column | description | unit |
|---|---|---|
| `peer_<market>_spread` | Peer's weekly mean modal price − Indore `y`. | Rs/qtl |
| `peer_<market>_ret_1w` | Peer's weekly log return. | log-return |
| `peer_avg_spread` | Mean of all peer spreads. | Rs/qtl |

## `global_markets` — futures, FX, edible oils
**Source:** yfinance (daily) + FRED (monthly). **Availability:** latest close with
`available_at ≤ cutoff` (FRED values lag the month end by `fred_publication_lag_days`, 35d).

| column | description | unit |
|---|---|---|
| `mkt_cbot_soybean` | CBOT soybean front-month close. | US cents/bushel |
| `mkt_cbot_soymeal` | CBOT soymeal front-month close. | USD/short ton |
| `mkt_cbot_soyoil` | CBOT soyoil front-month close. | US cents/lb |
| `mkt_brent` | Brent crude. | USD/barrel |
| `mkt_usdinr` | USD/INR exchange rate. | INR per USD |
| `mkt_usdbrl` | USD/BRL exchange rate. | BRL per USD |
| `mkt_dxy` | US dollar index. | index |
| `mkt_palm_oil_usd_t` | IMF/FRED palm oil price. | USD/tonne |
| `mkt_soyoil_usd_t` | IMF/FRED soybean oil price. | USD/tonne |
| `mkt_soybeans_usd_t` | IMF/FRED soybeans price. | USD/tonne |
| `mkt_soymeal_usd_t` | IMF/FRED soymeal price. | USD/tonne |
| `mkt_sunflower_usd_t` | IMF/FRED sunflower oil price. | USD/tonne |
| `cbot_soy_rs_qtl` | CBOT soybean converted to Rs/qtl (international parity, before freight/duty). | Rs/qtl |
| `cbot_board_crush_usd_bu` | CBOT board crush margin = 0.022·meal + 0.11·oil − beans. | USD/bushel |
| `soy_palm_oil_spread_usd_t` | Soy oil − palm oil price (wide premium → India buys palm instead). | USD/tonne |
| `mkt_<n>_ret_1w` / `mkt_<n>_ret_4w` | 1- and 4-week log returns, for `<n>` ∈ {cbot_soybean, cbot_soymeal, cbot_soyoil, usdinr, usdbrl, brent}. | log-return |

## `weather_season` — monsoon & crop-quality risk
**Source:** Open-Meteo ERA5 (catchment average of configured points). **Availability:** daily obs
through week_end; climatology baselines use **prior seasons only** (no future leakage). Season
year runs from 1 June (sowing).

| column | description | unit |
|---|---|---|
| `wx_rain_season_cum` | Cumulative rain since 1 Jun (counted to 31 Oct). | mm |
| `wx_rain_season_dep_mm` | Departure of season rain vs the same day in prior seasons. | mm |
| `wx_rain_season_z` | Z-score of season rain vs prior seasons (negative = deficit). | z |
| `wx_rain_harvest_cum` | Cumulative rain in the harvest window. | mm |
| `wx_rain_harvest_z` | Z-score of harvest rain (high = damage/quality-discount risk). | z |
| `wx_dry_spell_max` | Longest run of dry days in the growing period so far. | days |
| `wx_dry_spell_z` | Z-score of the dry-spell length vs prior seasons. | z |
| `wx_heat_days_flowering` | Days above `heat_threshold_c` during flowering. | days |
| `wx_heat_days_z` | Z-score of flowering heat days. | z |
| `wx_rain_days_season` | Count of rain days (≥ `dry_day_mm`) in the season so far. | days |
| `wx_season_quality_risk` | Composite: mean of harvest-rain, dry-spell, heat z-scores + ½ of any rain-deficit z. Higher = more yield/quality risk. | score |
| `wx_rain_wk` | This week's total rainfall. | mm |
| `wx_tmax_wk` | This week's mean daily max temperature. | °C |
| `wx_tmin_wk` | This week's mean daily min temperature. | °C |

## `global_supply` — USDA PSD balance sheets
**Source:** USDA FAS PSD. **Availability:** a marketing year's value is usable only from
`MY start + 15 months` (PSD stores latest-revision data, so this lag avoids look-ahead).

Pattern: `psd_<commodity>_<country>_<attribute>`
- `<commodity>` ∈ {soybean, soymeal, soyoil}
- `<country>` ∈ {world, united_states, brazil, argentina, india, china}
- `<attribute>` ∈ {production, ending_stocks, exports, imports, domestic_consumption}

| column | description | unit |
|---|---|---|
| `psd_<commodity>_<country>_<attribute>` | Latest known marketing-year value, e.g. `psd_soybean_brazil_production`. | 1000 MT |
| `psd_soybean_world_stocks_to_use` | World ending stocks ÷ domestic consumption (low = tight supply = supportive). | ratio |

## `policy` — MSP, duties, futures, policy news
**Source:** `config/seed_events.csv` + agent `policy_events`. **Availability:** an event counts
for week *W* only if known by *W*'s cutoff and in force on *W*.

| column | description | unit |
|---|---|---|
| `msp_effective` | Minimum Support Price currently in force. | Rs/qtl |
| `msp_latest_announced` | Latest announced MSP (incl. next season once announced). | Rs/qtl |
| `msp_change_pct` | `msp_latest_announced / msp_effective − 1`. | fraction |
| `spread_over_msp` | `y − msp_effective` (< 0 → mandi below MSP → procurement likely). | Rs/qtl |
| `ratio_to_msp` | `y / msp_effective`. | ratio |
| `duty_crude_soyoil_pct` | Effective import duty on crude soy oil. | percent |
| `duty_crude_soyoil_chg_8w` | Sum of duty changes over the last 8 weeks. | percentage points |
| `weeks_since_duty_change` | Weeks since the last duty change. | weeks |
| `futures_suspended` | 1 while soybean futures trading is suspended (and known), else 0. | 0/1 |
| `policy_bull_events_4w` | Count of bullish policy decisions over the last 4 weeks. | count |
| `policy_bear_events_4w` | Count of bearish policy decisions over the last 4 weeks. | count |

## `industry_stats` — SOPA / SEA / state statistics (agent)
**Source:** research agent (SOPA, SEA, the target state's agriculture dept). **Availability:** published date ≤
cutoff. Values converted to lakh units; `lt` = lakh tonnes, `lha` = lakh hectares.

For each `<metric>` there are two columns:

| column | description | unit |
|---|---|---|
| `ind_<metric>` | Latest published value of the metric. | lakh tonnes / lakh ha |
| `ind_<metric>_age_w` | Weeks since that figure was published (lets a model discount stale numbers). | weeks |

`<metric>` ∈ `sopa_crop_estimate_lt`, `sopa_crush_monthly_lt`, `sopa_stock_lt`,
`sopa_meal_export_lt`, `sea_soyoil_import_lt`, `sea_edible_oil_import_lt`,
`sea_edible_oil_port_stock_lt`, `state_soy_area_lha`, `state_soy_production_lt`,
`india_soy_area_lha`, `india_soy_production_lt`, `state_procurement_lt`
(`state_*` = the target market's state, e.g. Madhya Pradesh for Indore).

## `soy_products` — product prices & crush margin (agent)
**Source:** research agent (market reports). **Availability:** report date ≤ cutoff; weekly
median, carried forward ≤ 4 weeks.

| column | description | unit |
|---|---|---|
| `px_<product>_rs_qtl` | Weekly product price. `<product>` ∈ {soymeal_doc_local, soymeal_doc_export_fob, soy_oil_refined_local, soy_oil_crude_kandla, soy_plant_delivery_local, soyabean_local_mandi}. `*_local` = priced at the target market's hub; `export_fob`/`crude_kandla` are national benchmarks. | Rs/qtl |
| `crush_gpm_rs_qtl` | Gross product value of 1 qtl of seed = meal_yield·DOC + oil_yield·oil. | Rs/qtl |
| `crush_margin_rs_qtl` | `crush_gpm − y − processing_cost` (wide margin → crushers can bid more for seed). | Rs/qtl |
| `plant_vs_mandi_spread` | Plant-delivery price − Indore `y`. | Rs/qtl |

## `news_sentiment` — relevance-weighted news (agent)
**Source:** research agent (Tavily news + LLM scoring). **Availability:** article publish date ≤
cutoff. Sentiment is weighted by relevance × confidence; **NaN (not 0)** when there were no
articles, so "no news" ≠ "neutral news".

| column | description | unit |
|---|---|---|
| `news_count_wk` | Number of relevant articles this week. | count |
| `news_sent_wk` | Weighted mean sentiment this week (−1 bearish … +1 bullish). | score |
| `news_sent_4w` | Weighted mean sentiment over the last 4 weeks. | score |
| `news_count_4w` | Article count over the last 4 weeks. | count |
| `news_sent_ewm` | Exponentially-weighted sentiment (halflife 3 weeks). | score |
| `news_sent_<topic>_4w` | 4-week sentiment within a topic. `<topic>` ∈ {supply, demand, policy, weather, global}. | score |

**Source:** research agent (forecasts quoted in news/reports). **Availability:** publish date ≤

| column | description | unit |
|---|---|---|

## `calendar` — seasonality (known in advance)
**Source:** derived. **Availability:** fully known ahead of time.

| column | description | unit |
|---|---|---|
| `woy_sin`, `woy_cos` | Week-of-year encoded as sine/cosine (so week 52 sits next to week 1). | −1…1 |
| `month` | Calendar month. | 1–12 |
| `phase_sowing`, `phase_growing`, `phase_early_harvest`, `phase_peak_arrivals`, `phase_post_harvest`, `phase_lean` | Crop-phase one-hot dummies (exactly one is 1 each week). | 0/1 |
| `weeks_since_oct1` | Weeks since the 1 Oct crop-year start. | weeks |
| `diwali_week` | 1 if the week contains Diwali (mandis close around it, in peak arrivals). | 0/1 |
| `weeks_to_diwali` | Weeks until the next Diwali (99 if none ahead in range). | weeks |

## `target` — forward labels (NEVER use as model inputs)
**Source:** mandi_daily. These are the values a model predicts. Every `target_*` column is
excluded from the Time-LLM file. `h` ∈ `settings.target.horizons_weeks` (default 1, 2, 4, 8).

| column | description | unit |
|---|---|---|
| `target_y_fwd<h>` | The Indore price `h` weeks ahead, `y_{t+h}`. | Rs/qtl |
| `target_logret_fwd<h>` | Log return to `h` weeks ahead, `ln(y_{t+h} / y_t)`. | log-return |

### Notes
- **Which columns actually appear** depends on what you collected: skip a source (e.g. no USDA
  PSD, no agent run) and its columns are simply absent. The `target_history`, `arrivals`,
  `peer_mandis` and `calendar` groups need only `mandi_daily`.
- **`timellm_<market>_<commodity>.csv`** (named from `target` in settings, e.g.
  `timellm_indore_soyabean.csv`) is a trimmed view of the same table: date index, numeric
  covariates, target `y` last, **no `target_*` labels**, keeping columns ≥ 60% filled.
- **Coverage over time** (how filled each group is per year) is in
  `data/features/coverage_report.md`.
